# AWAY-MODE
Applies when I am not at the laptop (reading reports on a phone). Follow in addition to RULES.md.
- Confirm the branch before doing anything. Stop if it is not the branch named in the prompt.
- Push only when the prompt gives the exact push command. Never push to main. Never force push.
- If anything unexpected happens (a failing test you did not cause, a conflict, an unclear task), STOP and report. Do not work around it.
- Kill any app or server you started before you finish. Never leave a process running.
- Never modify production config or the data/ folder.
- Keep your final report to 8 lines or fewer: build result with test count, files changed, anything not verified, and anything that was blocked.
